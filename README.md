# ModdedQC Launcher

Custom Minecraft launcher for the **ModdedQC** server. Players log in with their Microsoft account and click **JOUER**. The launcher then:

1. downloads the latest `manifest.json` from your file server,
2. downloads every new or changed file (mods, configs, mod loader...) and deletes mods you removed,
3. installs Minecraft, its libraries, its assets and the correct Java version (from Mojang),
4. starts the game and connects directly to the server.

Built with Electron, using only `electron` and `electron-builder` (no other runtime libraries).

## Project layout

```
launcher.config.json     <- your file server URL + Azure client ID
src/main/main.js         <- window + buttons wiring
src/main/auth.js         <- Microsoft / Xbox / Minecraft login
src/main/modpack.js      <- syncs files from your server
src/main/minecraft.js    <- installs and starts Minecraft
src/main/download.js     <- parallel downloads with SHA-1 checks
src/renderer/            <- the UI (HTML / CSS / JS)
tools/build-manifest.js  <- generates manifest.json for the server
server-example/          <- example of what to put on the file server
```

## 1. Prepare the file server

The file server is any web server that serves static files over HTTPS (nginx, Apache, Cloudflare R2, GitHub Pages...). It contains:

```
pack.json          <- you edit this
manifest.json      <- generated
files/             <- exactly like a .minecraft folder
  mods/...
  config/...
  versions/1.20.1-forge-47.3.0/1.20.1-forge-47.3.0.json
  libraries/...    <- files generated by the Forge installer
```

### Adding Forge / NeoForge / Fabric

1. Create an empty folder and put a `launcher_profiles.json` file in it containing `{"profiles":{}}`.
2. Run the official Forge/NeoForge/Fabric installer, pick **Install client**, and select that folder.
3. Copy `versions/` and `libraries/` from that folder into `files/`.
4. Put the version folder name (for example `1.20.1-forge-47.3.0`) in `versionId` in `pack.json`.

For vanilla Minecraft, set `versionId` to the version number (for example `1.20.1`). Everything is downloaded from Mojang.

### pack.json

| Field               | Meaning                                                                              |
| ------------------- | ------------------------------------------------------------------------------------ |
| `name`, `version`   | Shown in the launcher. Bump `version` when you update the pack.                      |
| `versionId`         | Minecraft or mod loader version to start.                                           |
| `server`            | `host` and `port` of the Minecraft server.                                           |
| `autoConnect`       | `true` to join the server as soon as the game opens.                               |
| `syncDirs`          | Folders that must match the server exactly (extra files get deleted). Default `mods`. |
| `keepPlayerChanges` | Files downloaded only once, never overwritten (e.g. `options.txt`).                 |
| `news`              | List of `{ title, date, body, url }` shown on the home screen.                      |

### Publishing an update

```bash
node tools/build-manifest.js path/to/your/server-folder
```

Then upload the folder. Players get the update the next time they click **JOUER**.

## 2. Microsoft login (Azure)

Microsoft requires every launcher to have its own app ID:

1. Go to <https://portal.azure.com> → **App registrations** → **New registration**.
2. Supported account types: **Personal Microsoft accounts only**.
3. Redirect URI: platform **Public client/native (mobile & desktop)**, value `https://login.microsoftonline.com/common/oauth2/nativeclient`.
4. Copy the **Application (client) ID** into `azureClientId` in `launcher.config.json`.
5. Ask Microsoft to allow your app to use the Minecraft API: <https://aka.ms/mce-reviewappid>. Until it's approved, the login step fails with "Connexion aux serveurs Minecraft impossible".

## 3. Run and build

```bash
npm install
npm start          # run in development
npm run dist       # build the installer (.exe on Windows, .dmg on macOS, .AppImage on Linux)
```

Set `serverUrl` in `launcher.config.json` before building.

## Where files go on the player's PC

Game files are stored in `%APPDATA%\.moddedqc` (Windows), `~/Library/Application Support/.moddedqc` (macOS) or `~/.config/.moddedqc` (Linux). The **Paramètres** menu has a button that opens this folder and a slider to set RAM. The game output is written to `logs/launcher-latest.log`.
